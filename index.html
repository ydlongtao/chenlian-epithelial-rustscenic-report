Mouse Tumor Epithelial RustSCENIC Analysis

Motif-supported regulatory-network analysis of trusted epithelial subtypes across EC, SW, and YQ experimental groups.

Technical Summary

Primary result. A common, sample/subtype-balanced mouse GRN produced 73 motif-pruned regulons in the primary seed777 run and 65 regulons in the seed2026 sensitivity run. Sample-level testing identified 107 findings classified as stable and 28 as cautious under the prespecified FDR, effect-size, coverage, and seed-direction rules.

Interpretation. The strongest inferential evidence is within adequately represented subtypes in EC_vs_YQ and EC_vs_SW. Agr2/Pyy secretory-like and TFF1/AQP5 response-like epithelial programs are mainly EC-enriched and lack sufficient cross-group coverage; they remain descriptive rather than formally tested.

Statistical unit. Biological samples, not individual cells, were used for group comparisons. Each experimental group contains three samples, so the results support hypothesis prioritization and mechanistic follow-up rather than definitive causal claims.

Subtype composition is biologically informative but not a substitute for within-subtype inference

Subtype fractions vary across samples and groups. This composition view helps explain which epithelial programs are present, but group-level composition can confound whole-epithelium comparisons. The report therefore treats composition as descriptive and uses within-subtype sample-level comparisons for formal inference.

Regulon specificity highlights candidate subtype programs

Regulon specificity scores prioritize regulatory programs that distinguish one subtype from the others. These scores are useful for annotation and mechanism generation, but they do not establish that the TF is active in every cell or that the regulon is a direct causal driver.

Network and target enrichment results provide mechanistic hypotheses

Motif pruning requires mouse motif evidence and a minimum of 10 target genes. GO Biological Process and mouse-native Hallmark enrichment were used for target-set interpretation; KEGG was intentionally excluded. Network edges and enrichment terms should be validated against TF expression, regulon activity concordance, and independent perturbation or chromatin evidence.

Scope, Cohort, and Definitions

  • Species and genome: Mus musculus, mm10; TFs were taken from the RustSCENIC mouse TF list and motif evidence from the official Aerts Lab mm10 resources.
  • Input: Seurat RDS with 95,831 cells and 32,098 genes; 30,160 cells were epithelial by the finalized epithelial annotation.
  • Main cohort: 25,144 trusted epithelial cells across six subtypes: Agr2/Pyy secretory-like, AP-high differentiated, basal/keratinizing, hypoxia/ER-stress, proliferating epithelial/tumor, and TFF1/AQP5 response-like.
  • Excluded from GRN inference: unresolved cells, myeloid-like contamination, and tiny clusters. They were retained only for reference/QC scoring where applicable.
  • Experimental groups: EC, SW, and YQ, with three biological samples per group.
  • AUCell: calculated for all 30,160 epithelial cells; formal statistics used trusted cells and sample-level means.

Pipeline logic

  1. Read the finalized Seurat object and export epithelial raw counts, metadata, and UMAP coordinates.
  2. Filter genes using the trusted epithelial cohort, preserve integer raw counts in layers["counts"], and build H5AD inputs.
  3. Sample at most 500 cells per sample-by-subtype layer and at most 2,000 cells per subtype for one common GRN; use seeds 777 and 2026.
  4. Infer GRNBoost2 edges, perform cisTarget motif enrichment with mm10 rankings and MGI motif-to-TF annotations, and stop if motif pruning is empty.
  5. Score AUCell in all epithelial cells, then aggregate to sample-by-subtype means.
  6. Run limma empirical-Bayes comparisons on sample-level means, apply global and stratified FDR, and classify findings by robustness.
  7. Generate GO BP and mouse-native Hallmark target enrichment, figures, and the HTML report.

def stratified_balance(adata: ad.AnnData, seed: int) -> tuple[ad.AnnData, pd.DataFrame]:
    rng = np.random.default_rng(seed)
    obs = adata.obs
    selected: list[str] = []
    audit_rows: list[dict] = []
    for (subtype, sample), frame in obs.groupby(
        ["epithelial_subtype_final_v2", "sample_id_final_v2"], observed=True
    ):
        ids = frame.index.to_numpy()
        n_take = min(500, len(ids))
        take = rng.choice(ids, size=n_take, replace=False)
        selected.extend(take.tolist())
        audit_rows.append(
            {
                "seed": seed,
                "subtype": subtype,
                "sample_id": sample,
                "available": len(ids),
                "after_stratum_cap": n_take,
            }
        )

    stage1 = adata[selected].copy()
    final_ids: list[str] = []
    for subtype, frame in stage1.obs.groupby("epithelial_subtype_final_v2", observed=True):
        ids = frame.index.to_numpy()
        n_take = min(2_000, len(ids))
        take = rng.choice(ids, size=n_take, replace=False)
        final_ids.extend(take.tolist())
    final_ids = sorted(final_ids)
    balanced = adata[final_ids].copy()
    audit = pd.DataFrame(audit_rows)
    final_counts = balanced.obs["epithelial_subtype_final_v2"].value_counts()
    audit["final_subtype_total"] = audit["subtype"].map(final_counts)
    return balanced, audit


def main() -> None:
    OBJECTS.mkdir(parents=True, exist_ok=True)
    TABLES.mkdir(parents=True, exist_ok=True)

    matrix = mmread(INTERMEDIATE / "epithelial_all_counts.mtx.gz").tocsr().T
    obs = pd.read_csv(INTERMEDIATE / "epithelial_all_obs.tsv.gz", sep="\t")
    genes = pd.read_csv(INTERMEDIATE / "epithelial_all_genes.tsv.gz", sep="\t")
    umap = pd.read_csv(INTERMEDIATE / "epithelial_all_umap.tsv.gz", sep="\t")

    if matrix.shape != (EXPECTED_ALL, len(genes)):
        raise ValueError(f"Unexpected matrix shape: {matrix.shape}")
    if len(obs) != EXPECTED_ALL or obs["cell_id"].duplicated().any():
        raise ValueError("Unexpected or duplicated epithelial cell metadata")
    if genes["gene_symbol"].duplicated().any():
        raise ValueError("Duplicated gene symbols")
    if matrix.nnz and (matrix.data.min() < 0 or not np.allclose(matrix.data, np.rint(matrix.data))):
        raise ValueError("Counts must be non-negative integer-valued")

    obs = obs.set_index("cell_id")
    obs.index = obs.index.astype(str)
    for column in (
        "sample_id_final_v2",
        "group_final_v2",
        "epithelial_subtype_final_v2",
        "epithelial_state_final_v2",
        "epithelial_analysis_flag_final_v2",
        "epithelial_annotation_provenance_final_v2",
    ):
        obs[column] = obs[column].astype("category")
    if obs["epithelial_main"].dtype != bool:
        parsed_main = (
            obs["epithelial_main"]
            .astype(str)
            .str.strip()
            .str.lower()
            .map({"true": True, "false": False, "1": True, "0": False})
        )
        if parsed_main.isna().any():
            raise ValueError("Could not parse epithelial_main as boolean")
        obs["epithelial_main"] = parsed_main.astype(bool)
    if int(obs["epithelial_main"].sum()) != EXPECTED_MAIN:
        raise ValueError("Main epithelial cell count mismatch")

    umap = umap.set_index("cell_id").loc[obs.index]
    main_mask = obs["epithelial_main"].to_numpy()
    main_counts = matrix[main_mask]
    min_cells = int(np.ceil(0.01 * EXPECTED_MAIN))
    min_total = int(np.ceil(3 * 0.01 * EXPECTED_MAIN))
    detected = np.asarray((main_counts > 0).sum(axis=0)).ravel()
    total = np.asarray(main_counts.sum(axis=0)).ravel()
    symbols = genes["gene_symbol"].astype(str).to_numpy()
    technical = np.array(
        [bool(re.match(r"^(mt-|Rpl|Rps|Hba|Hbb)", gene)) for gene in symbols]
    )
    keep_genes = (detected >= min_cells) & (total >= min_total) & ~technical
    if keep_genes.sum() < 10_000:
        raise ValueError(f"Too few genes after filtering: {keep_genes.sum()}")

    matrix = matrix[:, keep_genes].astype(np.float32)
    var = pd.DataFrame(index=pd.Index(symbols[keep_genes], name="gene_symbol"))
    var["n_cells_main"] = detected[keep_genes]
    var["total_counts_main"] = total[keep_genes]
    adata_all = ad.AnnData(X=matrix, obs=obs.copy(), var=var)

def candidate_regulons(grn: pd.DataFrame, top_n: int = 50) -> dict[str, list[str]]:
    result: dict[str, list[str]] = {}
    for tf, frame in grn.groupby("TF", sort=True):
        targets = frame.nlargest(top_n, "importance")["target"].astype(str).tolist()
        targets = list(dict.fromkeys(targets))
        if len(targets) >= 10:
            result[f"{tf}_regulon"] = targets
    return result


def prepare_smoke(adata: ad.AnnData, seed: int) -> ad.AnnData:
    rng = np.random.default_rng(seed)
    if adata.n_obs > 1_000:
        ids = rng.choice(adata.obs_names.to_numpy(), 1_000, replace=False)
        adata = adata[sorted(ids)].copy()
    work = adata.copy()
    sc.pp.highly_variable_genes(work, n_top_genes=min(3_000, work.n_vars), flavor="seurat")
    tfs = {x.strip() for x in TF_FILE.read_text().splitlines() if x.strip()}
    keep = work.var["highly_variable"].to_numpy() | work.var_names.isin(tfs)
    return work[:, keep].copy()


def write_json(path: Path, value: object) -> None:
    path.write_text(json.dumps(value, indent=2, ensure_ascii=False))


def run(seed: int, smoke: bool) -> None:
    label = "smoke" if smoke else f"seed{seed}"
    run_dir = RUST_OUT / label
    run_dir.mkdir(parents=True, exist_ok=True)
    input_path = OBJECTS / f"epithelial_grn_balanced_seed{seed}.h5ad"

    if smoke:

    tf_names = [tf for tf in tf_reference if tf in adata.var_names]
    if len(tf_names) < (500 if smoke else 900):
        raise RuntimeError(f"Insufficient mouse TF overlap: {len(tf_names)}")

    n_estimators = 50 if smoke else 1_000
    timings: dict[str, float] = {}
    started = time.perf_counter()
    grn = rustscenic.grn.infer(
        adata,
        tf_names=tf_names,
        n_estimators=n_estimators,
        target_block_size=None,
        seed=seed,
        verbose=True,
    )
    timings["grn_seconds"] = time.perf_counter() - started
    if grn.empty or not {"TF", "target", "importance"}.issubset(grn.columns):
        raise RuntimeError("GRN output is empty or malformed")
    grn.to_parquet(run_dir / "grn.parquet", index=False)

    candidates = candidate_regulons(grn, top_n=50)
    if not candidates:
        raise RuntimeError("No candidate regulons with at least 10 targets")
    write_json(run_dir / "candidate_regulons.json", candidates)

    started = time.perf_counter()
    rankings = _coerce_rankings(RANKINGS_FILE, feature_names=adata.var_names)
    if rankings.empty:
        raise RuntimeError("Projected motif rankings are empty")
    enriched = rustscenic.cistarget.enrich(
        rankings,
        list(candidates.items()),
        top_frac=0.05,
        auc_threshold=0.05,
        nes_threshold=3.0,
    )
    timings["cistarget_seconds"] = time.perf_counter() - started
    enriched.to_parquet(run_dir / "cistarget_enriched.parquet", index=False)
    annotations = pd.read_csv(ANNOTATIONS_FILE, sep="\t", low_memory=False)
    pruned = rustscenic.cistarget.prune_regulons(
        enriched,
        list(candidates.items()),
        annotations,

        auc_threshold=0.05,
        nes_threshold=3.0,
        min_genes=10,

        tf_col="gene_name",
        case_sensitive=False,
    )
    if not pruned:
        raise RuntimeError(
            "Motif pruning produced zero regulons; refusing candidate-only fallback"
        )
    write_json(run_dir / "pruned_regulons.json", pruned)

    score_input = adata if smoke else ad.read_h5ad(OBJECTS / "epithelial_all_rustscenic_input.h5ad")
    common_genes = score_input.var_names.intersection(adata.var_names)
    score_input = score_input[:, common_genes].copy()
    started = time.perf_counter()
    auc = rustscenic.aucell.score(
        score_input,
        list(pruned.items()),
        top_frac=0.05,
    )
    timings["aucell_seconds"] = time.perf_counter() - started
    if auc.empty or not np.isfinite(auc.to_numpy()).all():
        raise RuntimeError("AUCell output is empty or non-finite")
    auc.to_parquet(run_dir / "aucell.parquet")

    integrated_path = run_dir / "epithelial_all_with_regulon_auc.h5ad"
    score_input.obsm["X_regulon_auc"] = auc.loc[score_input.obs_names].to_numpy(np.float32)
    score_input.uns["regulon_names"] = np.asarray(auc.columns.astype(str), dtype=str)
    score_input.uns["rustscenic_seed"] = seed
    score_input.uns["regulon_source"] = "mm10_v10_motif_annotation_pruned"
    score_input.write_h5ad(integrated_path, compression="gzip")

    target_counts = pd.DataFrame(
        {"regulon": list(pruned), "n_targets": [len(v) for v in pruned.values()]}
    )
    target_counts.to_csv(run_dir / "regulon_target_counts.tsv", sep="\t", index=False)
    manifest = {
        "label": label,
        "seed": seed,
        "smoke": smoke,
        "n_estimators": n_estimators,
        "grn_cells": adata.n_obs,
        "grn_genes": adata.n_vars,
        "candidate_tfs": len(tf_names),
        "grn_edges": len(grn),

def sample_means(seed: int, obs: pd.DataFrame) -> pd.DataFrame:
    auc = pd.read_parquet(RUST_OUT / f"seed{seed}" / "aucell.parquet")
    auc.index = auc.index.astype(str)

    meta = obs.loc[common]

    auc = auc.loc[meta.index]
    keys = ["epithelial_subtype_final_v2", "sample_id_final_v2", "group_final_v2"]
    rows = []
    grouped = meta.groupby(keys, observed=True)
    for (subtype, sample_id, group), index in grouped.groups.items():
        means = auc.loc[index].mean(axis=0)
        frame = means.rename("mean_auc").reset_index()
        frame = frame.rename(columns={frame.columns[0]: "regulon"})
        frame["seed"] = seed
        frame["subtype"] = str(subtype)
        frame["sample_id"] = str(sample_id)
        frame["group"] = str(group)
        frame["n_cells"] = len(index)
        rows.append(frame)
    return pd.concat(rows, ignore_index=True)


def target_stability(reg_a: dict[str, list[str]], reg_b: dict[str, list[str]]) -> pd.DataFrame:
    rows = []
    for name in sorted(set(reg_a) | set(reg_b)):
        a, b = set(reg_a.get(name, [])), set(reg_b.get(name, []))
        union = a | b
        rows.append(
            {
                "regulon": name,
                "present_seed777": name in reg_a,
                "present_seed2026": name in reg_b,
                "n_targets_seed777": len(a),
                "n_targets_seed2026": len(b),
                "target_jaccard": len(a & b) / len(union) if union else np.nan,
            }
        )
    return pd.DataFrame(rows)


def expression_activity_concordance(
    adata: ad.AnnData, means: pd.DataFrame, regulons: dict[str, list[str]]
) -> pd.DataFrame:
    main = adata[adata.obs["epithelial_main"].astype(bool)]
    keys = ["epithelial_subtype_final_v2", "sample_id_final_v2", "group_final_v2"]
    tf_by_reg = {name: name.removesuffix("_regulon") for name in regulons}
    tf_by_reg = {reg: tf for reg, tf in tf_by_reg.items() if tf in main.var_names}
    rows = []
    for key, index in main.obs.groupby(keys, observed=True).groups.items():
        subtype, sample_id, group = map(str, key)
        positions = main.obs_names.get_indexer(index)
        matrix = main.X[positions]
        for regulon, tf in tf_by_reg.items():
            gene_index = main.var_names.get_loc(tf)
            values = matrix[:, gene_index]
            mean_expression = float(values.mean()) if sparse.issparse(values) else float(np.mean(values))
            rows.append(
                {
                    "regulon": regulon,
                    "tf": tf,
                    "subtype": subtype,
                    "sample_id": sample_id,
                    "group": group,
                    "mean_tf_expression": mean_expression,
                }
            )
    expression = pd.DataFrame(rows)
    merged = expression.merge(
        means.loc[means["seed"] == 777],
        on=["regulon", "subtype", "sample_id", "group"],
        how="inner",
    )
    summaries = []
    for (regulon, tf), frame in merged.groupby(["regulon", "tf"]):
        if len(frame) >= 6 and frame["mean_tf_expression"].nunique() > 1 and frame["mean_auc"].nunique() > 1:
            rho, pvalue = stats.spearmanr(frame["mean_tf_expression"], frame["mean_auc"])
        else:
            rho, pvalue = np.nan, np.nan
        summaries.append(
            {"regulon": regulon, "tf": tf, "n_units": len(frame), "spearman_rho": rho, "pvalue": pvalue}
        )
    result = pd.DataFrame(summaries)
    result["fdr"] = stats.false_discovery_control(result["pvalue"].fillna(1).to_numpy())
    return result

                      pmax(ncol(a) + ncol(b) - 2, 1))
  raw_delta <- rowMeans(a) - rowMeans(b)
  effect <- raw_delta / pooled_sd
  effect[!is.finite(effect)] <- 0
  tt[, `:=`(
    seed = seed_value,
    subtype = subtype_value,
    contrast = contrast_name,
    group_a = groups[1],
    group_b = groups[2],
    raw_delta_auc = raw_delta[regulon],
    standardized_effect = effect[regulon],
    n_samples_a = ncol(a),
    n_samples_b = ncol(b)
  )]
  tt
}
